# Laborator 1 - Introducere în programarea cross-platform utilizând Flutter

## Varianta 1. Calculator de reducere

### Cerințe Implementate:
- **Input:**
  - Preț inițial (TextField)
  - Procentul reducerii (TextField)
- **UI Controls:**
  - `TextField` pentru preț inițial și procentul reducerii
  - `DropdownButton` pentru selecția valutei sau categoriei
  - `RadioButton` pentru selecția rapidă a procentului (10%, 20%, 30%, 50%, Personalizat)
  - `ElevatedButton` pentru declanșarea calculului
- **Output:**
  - Valoarea reducerii (Text)
  - Prețul final după reducere (Text)
- **Design:** Google Material 3 (Material You)
